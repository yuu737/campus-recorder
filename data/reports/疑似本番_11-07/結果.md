## 本番用の直しの一覧（詰まり.json から、効く順に）

1. **事件の検出が本番の流れを毎棟止める**（J-011・J-025・J-028・J-015）：`recorder/agents.py _building_events`
   - 「敷地に置く物」や道具の不足の `kind: tool` が全部 vocab の事件になる → 4 棟とも測量・設計の後に vocab が出た。本番の `run_pipeline` は vocab で止まる。tool を語彙と道具の不具合に分け、後者は記録だけにする
   - stuck が「写真×線」の本数で数える（567・360・276 本）→ 検収の後で毎棟止まる。面ごと・写真の中央値で数え、1 組の登録に偏る NG を除く
   - `soten.json` の open でも `rule` の欄が埋まっていると事件に出ない／棟 JSON の `kind: check` は事件に出ない → 規則で決まらない争点を本番の進行役が見落とす
2. **使用量・速度の上限と再開**（J-014・J-029）：`run_pipeline`。仕分け〜測量だけで 1 棟 120〜150 万トークン（文脈の大きさの目安）。429 で落ちた工程を会話を保ったまま続きから再開する仕組みと、呼び出しごとの usage（入出力・cache）の合計を記録に
3. **台帳の鍵を照合の間持たない**（J-012）：`recorder/__main__.py` の LEDGER_WRITERS・`recorder/registry.py`。register-chain・register-sfm は「読む→計算→鍵を取って読み直し→差分を書く」に
4. **登録の外し方と周期の取り違え**（J-027・J-013）：`recorder/registry.py`。本部棟 f6 の 3 枚が柱割り 4 つ分（21.7 m）ずれて登録され、検収で見つかった。`photos unregister`・`photos exclude` のコマンド、周期の面では端か唯一の部品の対応を必須に。coverage は隠れを見る
5. **目印の一覧に部品・窓の縁を入れる**（J-018・J-024）：`recorder/landmarks.py`。柱割りの無い面（図書館 f0・f2）と部品に隠れる面で目印係の登録が伸びない（本部棟 62 枚中 10、図書館 46 枚中 4、共通講義棟南 14 枚中 3）
6. **--zero が決定の台帳を空にし、語彙・アセットの参照が切れる**（J-001・J-016）：`scripts/trial_reset.py`・`recorder agent decide`。初期語彙の承認を残し、decide に --supersede と --by を
7. **土台（recorder new --from-site）の 4 つの癖**（J-009・J-010・J-022・J-006）：`recorder/skeleton.py`。面の長さの ± が validate の下限より小さい、parapet_top が PLATEAU の最高（塔屋込み）で compare の高さの原点が 8 m ずれる、輪の閉じ点で長さ 0 の辺、面の名前の番号のずれ
8. **敷地の検収係を工程に入れる**（J-020）：`recorder/agents.py` の STEPS。図書館とタワー75 の間のデッキを片方は敷地へ、片方は棟に置いた（同じ物の恐れ）
9. **pnp の門のすり抜け**（J-026・J-019）：焦点が探索の端に張り付いた解・地上から 5 m 超のカメラを不合格に。線の対応があれば既定で poselib
10. **set-face が別の棟の写真の面を上書きできる**（J-004）：`recorder/photos.py set_faces`
11. **証拠ビューア・歩く画面の絵が撮れない**（J-030）：`recorder/shots.py`。headless の Edge が DevTools の口を開かない。**疑似本番の後、21:06〜21:11 に同じ道具をそのまま動かして 4 棟とも撮れた**（原因は再現せず。下の「報告の絵について」）
12. **Blender の EXACT が同一平面で壊れる**（J-017）：`recorder/blender_build.py`。設計係が塊を 1〜13 cm 寄せて回避
13. 手順・係の定義（J-021・J-023・J-005・J-007・J-008・J-002・J-003）：一直線の面をまとめる規則と面ごとの登録の食い違い、目印係が棟 JSON を直接書いた、観察票の見本が退避されて無い、同時の係が作業フォルダを共有してぶつかる、短い Markdown の置き場、撮影係の出力の置き場、撮影係が顔・掲示物を目視しない
