## objects の形
```json
"objects": {"schema": "campus-recorder/site-objects/1", "note": "…", "items": [ {物}, … ]}
```
物の共通の欄：`id`・`type`・`name`・`evidence`（物があることの根拠＝写真 id）・`seen`（写真で見えた事の文）・`requests`（棟 JSON と同じ形の依頼）・`refs`。
値は全部、棟 JSON と同じ `{"value","unit","tol","status","evidence","method","note"}`（measured／estimated／unknown）。

| 型 | 値の欄（★は必須。分からなければ unknown で置く） | 描き方 |
|---|---|---|
| `bridge` 通路橋 | `ends[2]`：`building`・`face`・★`along0`・★`along1`（面の始点から m）・★`z`（**その棟の z=0 から** m）／★`floor_z`（標高 m）・`parapet_height`・`beam_depth` | 両端の面の区間の 4 点を結んだ四角の床板（座標は棟 JSON の面から計算。二重に書かない）。腰壁・桁は値がある時だけ |
| `deck` 甲板 | ★`polygon`（value が `[[x,y],…]`）・★`z`（標高）・`thickness` | 多角形の板 |
| `steps` 棟の間の段・広場の段 | ★`polygon`（4 点：下の縁 2 点→上の縁 2 点）・★`z0`・★`z1`・★`count`（段） | 段の数だけの箱。段の数が unknown なら描かない（なめらかな坂にしない） |
| `asset` CC0 の置物 | `asset`（`data/assets/catalog.json` の id）・★`position`（`[x,y]`）・`z`・`rotation_deg` | glb には描かず、`site.json` の `site_objects.assets` に位置だけ |

検証（`validate_objects`）：根拠の写真の無い measured は誤り（`osm:`・`plateau:`・`gsi:` は写真と数えない）／measured の長さは `chain` が要り、輪は `tape|count|px_ratio|uniform_period` だけ、各輪に写真 id（K-101。T1 と同じ決まりを自分のモジュールで見る）／estimated は evidence と method が要る／unknown は value が null／橋の両端の棟が `data/buildings/` にあり、面がその棟 JSON にあり、along が面の長さの中／asset は CC0 の台帳にある id／unknown がある物に open の依頼が無ければ警告。誤りがあれば `write_objects` は書かず、export は glb を出さない。

## 通路橋の実例（`bridge-library-tower75`）
写真は縮小（長辺 900 px）して 6 枚だけ見た：図書館側 `PXL_20261105_063412307`・`063439559`・`PXL_20261103_075517975`、タワー75 側 `PXL_20261103_070409570`・`070422004`・`PXL_20261105_062246708`。
見えた事：構内の道（OSM way/163508476）をまたぐ 1 本の橋。床は煉瓦色、両側にタイルの腰壁＋笠木＋金属の手すり、下面はコンクリートの桁と横の梁、下を車が通る。図書館側は青い鉄骨の庇の甲板に段差なしで続き、タワー75 側は西のデッキの南西の端に付く。**図書館の依頼の「通路橋」とタワー75 の依頼の「S2 南西のデッキの橋」は同じ橋**（同じ道・同じ桁が両方の写真に写る）。

| 値 | 値 | 状態 | 根拠と方法 |
|---|---|---|---|
| 図書館の端 f1 `along0` | 41.53 m ±0.4 | estimated | OSM way/1304081004（甲板と通路橋の多角形）の頂点 (24.01, −3.44) を f1 に投影（面から 0.01 m） |
| 図書館の端 f1 `along1` | 49.42 m ±0.4 | estimated | f1 の終点（北西の角）。063412307・063439559 で西の腰壁が一直線に甲板の北西へ届く。甲板がさらに西へ広がるので角で切った（依頼 4） |
| 図書館の端 `z` | 6.6 m ±1.39（棟の z=0 から） | estimated | 図書館の甲板の床（棟 JSON の風除室 z0 と同じ、design_library.DECK_Z）。床は段差なしで続く |
| タワー75 の端 f4 `along0`〜`along1` | 0〜5.98 m ±0.3 | estimated | f4 の両端＝OSM の頂点。橋は f4 の幅いっぱい（070409570） |
| タワー75 の端 `z` | 7.23 m ±2.7（棟の z=0 から） | estimated | タワー75 の 1F（西のデッキ）。観察票 S2「橋の床はデッキ階と同じ高さ」 |
| `floor_z` 床の高さ | 標高 48.76 m ±1.5 | estimated | 両端の標高（図書館 48.27 ±1.71、タワー75 50.13 ±2.88。± は端の z と ground_z ±1.0 の二乗和）の ± の逆二乗の重み付き平均。床は両側と段差なしなので 1 枚の高さで置いた。坂か水平かは決めていない |
| `parapet_height` 腰壁の高さ | null | unknown | 物差しが無い → 撮影依頼 1 |
| `beam_depth` 桁の厚さ | null | unknown | 斜めの写真だけ → 撮影依頼 2 |

計算で出る形：図書館側の幅 7.9 m、タワー75 側 6.0 m、長さ約 15.3 m（四角の辺。値としては書かず、面から計算）。
依頼（`objects[0].requests`、open 4 件）：①腰壁にメジャー（職員）②道から橋の側面を真横から・桁の下面（職員）③**両端の床の標高が 1.86 m 違う**（図書館 48.27・タワー75 50.13。± の中では合うが差が大きい。どちらかの棟の値を直す。図書館の甲板から撮った組の視点の高さの食い違い（library.json の check）と関係しそう）④図書館側の端を角で切ったのでよいか（甲板を置く時に）。
`site objects check` の結果：橋の床と図書館の端 +0.49 m（±3.21）OK、タワー75 の端 −1.37 m（±4.38）OK、両端の差 +1.86 m（±4.59）OK。誤り 0・警告 0。
棟 JSON の依頼（library の「通路橋」、tower75 の「S2」）は閉じていない（後で設計係）。

## 歩く画面への出し方
- `recorder site export-web [--out <フォルダ>]` の中で `site_objects.export_web_objects` が `<out>/data/models/site_objects.glb` を書き、`site.json` の `models["site-objects"] = {"url": "data/models/site_objects.glb", "ground_z": 0}` に足す。glb の軸は棟の glb と同じ（glTF の Y が上：x＝東、y＝標高、z＝−北）で、高さは標高そのものなので ground_z は 0。**`web/index.html` は棟の glb と同じ読み込み（`site.models` を回す所）でそのまま置く。index.html は変えていない。**
- `site.json` に `site_objects`（物ごとの状態の数・根拠の写真・描いたか・open の依頼の数、置物の位置、描かなかった欄と理由）を足した。
- unknown の欄は描かない。床の厚さ（桁）が unknown の時は 0.05 m の線の太さで板を描く（描画の都合で寸法ではない。JSON には書かない）。
- 単独で：`recorder site objects export --out <フォルダ>`（`--out` は必須。`web/data/` は既定にしない）。

## できなかった事と理由
- 歩く画面をブラウザで開いて橋が見えるかは確かめていない（`web/data/` を上書きしないため。一時フォルダの site.json を開けば見える作り）。
- 置物（asset）を glb に描くこと：CC0 のモデルを Blender なしで glb に組むのは今回の範囲外。位置だけ site.json に出す。歩く画面で置くには index.html に数行が要る（担当外なので触っていない）。
- 実例の腰壁・桁の寸法：写真に物差しが無く読めないので unknown と依頼。
- ほかの open の依頼（甲板・青い鉄骨の庇・斜路・路地の段・大階段・渡り廊下 S3・S8・S9・広場・木・街灯）は置いていない（指示は実例 1 つ）。型は用意したので設計係が置ける。
