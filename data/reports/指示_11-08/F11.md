# F11 灰色の箱を締める（寄せ・見た目）

利用者の指示「壁が見える方が根拠が見える。文字は目立つ色にして箱に乗せる必要はない」に合わせた。
10×10 の升の箱は粗く、垂れ幕 3 本が本部棟 f6 の壁の大きな一塊を隠していた。

## 作った物
### 1. 寄せ（refine）の工程（recorder/photos.py）
- `photos hogo-grid --refine --photos <id,…>`（または `--building <棟>`）：索引の masks のうち保護係・見直し（hogo／review）の箱ごとに、
  箱を各側に箱の幅・高さの 25 % 広げて切り出し（目印係の寄りと同じ 1.5 倍）、10×10 の升目と**元の箱の赤い線**を引いた絵
  `out/photos/hogo_refine/<id>_<n>_grid.jpg`（n は索引の masks の番号、長辺 1200、拡大は 4 倍まで）と依頼
  `tasks_refine[_<棟>].json`（photo・n・kind・box・region・grid・write_to）を出す。絵は元の写真から切り出す（顔の自動の箱は塗ってから）。索引は書かない。
- `photos masks --pass refine --from out/photos/hogo_refine[_<棟>].json`：
  `{"pass":"refine","photos":{id:[{"n":1,"box":[元の箱],"cells":["C2:D9","G2:H9"],"note":…}]}}` で箱を置き換える。
  - 新しい箱は**元の箱の中に切り詰める**（広げない）。赤い線の外だけを指した升は errors。
  - 分けてよい（cells を複数）。kind・by（hogo／review のまま）・note を引き継ぎ、`box_before`（元の箱）と `refined`（by・at・cells）を残す。
  - 番号の箱が無い・auto の箱・`box` が依頼の時と違う・cells が空・升の書き方違い → その写真は書かない。
  - 見直しの `drop` は元の升（box_before）でも外せるようにした。`photos masks --pass hogo` のやり直しは寄せた箱も置き換える（今まで通り）。
- `.claude/agents/hogo.md` に「寄せの時」（1 段、目印係の寄りと同じ言い方）と冒頭の「壁が見える方が根拠が見える」。

### 2. 見た目（recorder/privacy.py の paint_masks。公開版・係に見せる縮小版・保護係の升目の絵の全部）
- (a) 隠す範囲だけ不透明の灰色 #8a8a8a (b) 内側 2 px の濃い縁（#282828。外へ出さないので塗る範囲は広がらない）
- (c) 箱の左上の隅に札：濃い帯（#1e1e1e）に白の文字、文字の高さは写真の高さの 2 %（1600×1200 なら 24 px、一定）。箱が小さければはみ出す。
  隣の札と重なる時は下へずらす（試しで「掲示 掲示物」と欠けたため足した）。
- (d) 同じ種類で重なる・接する（1 px の隙間まで）箱は 1 つにまとめ、**箱の和**で塗る（外接の長方形にしない）。札は 1 回。種類が違えば別。
- (e) 札は 顔・ナンバー・人名・掲示物・電話番号（privacy.KINDS のまま）。

## 追記（Fable、利用者「顔はあかんやろ」：石垣の上の誤検出に「顔」の札）
決まり：自動（YuNet）の顔の箱は、見直し係が切り出しを見て「顔である」と確かめた物だけ残す。
- `hogo-grid --refine --auto`：by: auto の顔の箱も同じ形（各側 25 %）で切り出す。依頼 JSON の行に `by: auto`・`kind: face`・`score`・`ask`。
  切り出しでは自動の顔の箱を塗らない（顔かどうかを見るため。out/ の係用の絵）。小さな箱が見えるよう拡大の上限を 4 → 8 倍に。
- 答え方：寄せの JSON（`masks --pass refine`）で `{"n": 0, "confirm": true}`（`cells` で締めてよい）か `{"n": 0, "drop": true}`。
  見直しの JSON（`masks --pass review`）では写真ごとに `"auto": [{"n": 0, "confirm": true}, …]`。どちらも無ければ errors。
  confirm → `by: review`・`confirmed: {by, at, from: "auto"}` で残す（review のやり直しでも消さない）。drop → masks から外し、写真の `dropped_auto` に元の箱と score を残す。
- `publish`・`send`（縮小版）・保護係の升目の絵：確かめていない auto の箱は**描かない**（索引には残す。privacy.drawn_masks）。
  publish の集計に「未確認の自動の顔 n」（`auto_unconfirmed`、塗りつぶしの数・種類別の箱からは外した）。
- hogo.md：見直しの節に「自動の顔の箱は切り出しを見て confirm か drop を必ず書く」。指す物の表の face と、升目の絵の説明も「自動の箱は描かれていない」に直した。
- テスト 3 件（`--auto` の切り出しと score、confirm／drop（review と refine の両方、やり直しで消えない）、描かない）。既存の
  test_privacy 1 件・test_publish 2 件は「自動の顔を描く」前提だったので「描かない・auto_unconfirmed で数える」に直した。
- 確かめ：写しで PXL_20261104_074357308 の自動の顔（score 0.719）を切り出して見た → 植え込みの葉で顔ではない → drop。
  公開版 `out/_mock/refine_PXL_20261104_074357308_auto.jpg` で石垣の上の「顔」の札が消えた（垂れ幕の寄せも同時）。写し `out/_mock/f11/index_after_auto.json`。
- 全体の pytest：677 通過・1 失敗（`tests/test_serve.py::test_artifacts_lists_only_existing_files`）。F8 が serve.py の `_shown_masks` に同じ決まり（auto を描かない）を入れた所で、
  その試験がまだ auto の顔の札「顔」を期待している。serve.py・test_serve は F8 の担当なので触っていない。
- 注意：ディスクにある既存の縮小版 `send/*.jpg` は古い描き方（自動の顔を塗った物）のまま。作り直すなら `photos send --force`
  （顔を探し直すので auto の箱は新しく付き直る。確かめた顔は by: review で残るので、同じ所に未確認の auto が重なる。見直しで drop する）。

## 追記 2（Fable、本番の寄せ 8 本で出た食い違い）
- `masks --pass refine`：
  - auto 以外の箱にも `{"n": …, "drop": true, "note": 理由}` を受け付けて外す。写真の `dropped` に kind・元の箱・box_before・by_was・cells・`dropped_by: "refine"`・note・made_by・at を残す。
  - **項目ごと**に確かめ、だめな項目だけ飛ばして同じ写真の他の箱は書く（前は 1 項目のエラーで写真ごと書かなかった）。同じ n が 2 回 → その項目はエラー。
  - 元の箱の外の升が混ざった時は外の升だけ捨て、`warnings`（id・n・cells）に残して中の升で書く。全部が外ならその項目はエラー。
  - confirm＋cells は cells が書けた時だけ confirmed に数える。
  - 結果 JSON に `written`（書いた写真）・`skipped`（何も書かなかった写真）・`errors`（項目ごと、id・n・item・error）・`warnings`・`dropped`。
- `masks --pass review`：`drop` に元の升（"C3:E5"）のほか**箱の番号**（`3` か `{"n": 3}`）を書ける（寄せた後の箱用）。
  `"confirm": [n, …]` で自動の顔を番号で確かめられる（`"auto": [{"n", "confirm"|"drop"}]` も今まで通り）。番号で外した箱も写真の `dropped`（auto なら `dropped_auto`）に `dropped_by: "review"` で残す。
  結果に `written`・`skipped`。review の項目は写真単位で確かめる（番号が無い等は写真ごと skipped、errors に理由）。
- テスト：tests/test_photos_hogo_refine.py の「エラーなら写真ごと書かない」5 通りを「その項目だけ飛ばし他は書く」に直し、新しく 2 件（refine の drop と外の升の切り捨て・skipped、review の番号での drop と confirm）。全体の pytest **682 件通過**。
- 本物の索引の写しに `out/photos/hogo_refine_1〜8.json` を当て直してみたが、本物の索引はもう寄せ済みなので全部「箱が依頼の時と違う」で止まった（二重に当たらない確かめにはなった）。
  20261105_165235743 n=7 の I4:J5 の再現は写しでは出来ず、同じ形の試験（外の升の切り捨て）で確かめた。寄せで書けなかった項目を当て直すなら、その写真だけ `hogo-grid --refine --photos <id>` で絵と番号を出し直してから。
