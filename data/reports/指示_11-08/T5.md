## 2. J-013・J-027 登録の外し方
### 使い方
```
# 登録を外す（理由は unregistered[] に、元の登録ごと残る。写真は次の register-chain で試し直される）
python -m recorder photos unregister <写真id> --why "地面を直す前の登録" [--building honbu] [--face f6] [--by sokuryo]

# 写真ごと使わない（登録を外し、excluded[] に書く。以後は鎖・SfM・目印で試し直しても台帳に入らない）
python -m recorder photos exclude <写真id> --why "柱割り 4 つ分ずれる" [--building honbu]
python -m recorder photos exclude <写真id> --lift            # 除外をやめる（登録は戻さない）

# 面の矩形だけ使わない（木・車など。面の m の s0,s1,z0,z1。plane の登録は exclude、pose は exclude_by_face[面] に入る）
python -m recorder photos exclude <写真id> --face f6 --rect 0,3,0,2 --why "木"
```
- 写真 id は頭か末尾だけでも通る（2 枚以上に当たれば止まる）。どれも `--registry` で台帳の場所を変えられる。
- 一時フォルダの写しで J-027 の 3 枚（042822099・042830256・042844361、honbu f6）を外せることを確かめた（188 件 → 185 件、`unregistered` 3 件）。

### 周期の面の原点の確かめ（J-027）
- 柱割り（`bays.count`）が 3 以上の面を「周期の面」とする。`upsert`（全部の登録の入口）が台帳に入れる前に `anchor_check` で確かめる。原点が決まらなければ入れず、前の登録はそのまま残し、`not_registered` に `anchor_reason`・`anchor_code: origin_ambiguous` を書く。
- 「原点が決まる」の条件は次のどれか：
  - 周期の面が写っていない。
  - 周期でない面も見えている（その面が位置を決める）。
  - 面の端（角・妻）か、その面に 1 つしか無い種類の部品（玄関など）が入っている。何で見るかは登録の種類で違う：目印の登録は目印係が指した点・線の位置、鎖・SfM・正面化は写真に写る範囲。
- 通った時は `check.anchor` に理由を書く。試しの時だけ `RECORDER_ANCHOR_CHECK=0` で切れる。
- 今の台帳（188 件）に読むだけで当てた結果：止まるのは 2 件（本部棟 f8 の目印の登録 043314396・043320836）。**J-027 の 3 枚は通ってしまう**（ずれた視点でも f6 の西の端が写っているため）。理由は「できなかった事」の 1 に書いた。

### 隠れ（J-013 の coverage の側）
- `expand_entries` は、登録した時の `visible_faces` を使うのをやめ、**今の棟 JSON の面で見え直す**ようにした（枠に入り、棟の他の面に隠れない所が 2 m² 以上の面だけ）。今の台帳だと、タワー75 で見えない面への割り当てが 8 組外れ、共通講義棟南で 2 組増える。他の 2 棟は変わらない。
