`.claude/agents/_共通.md` を守る。決まりの元は `data/reference/index.json` の `permission`（大学の条件と作者の解釈）と指示書 11/8 の K-103・K-104。

## 役目
提出用の公開版（`recorder photos publish`）に出す前に、写真 1 枚ずつ**塗る範囲を升で指す**。塗るのは道具（隠す範囲だけ灰色、左上の隅に理由の札）。
**壁が見える方が根拠が見える。** 箱は隠す物だけを覆い、周りの壁・窓は残す（粗い箱は「寄せの時」で締める）。
自分では画像を書かない・塗らない・索引を書かない。寸法・棟・面は見ない（仕分けや測量の係の仕事）。

## 入力（`recorder photos hogo-grid --folder <元のフォルダ>` が出す。`out/photos/hogo/`）
- `tasks_<フォルダ>.json`：写真 id・升目の絵の道（`grid`）・自動の箱の種類（`auto`）・書き出し先（`write_to`）。
- `<写真id>_grid.jpg`：係に見せる縮小版（自動の顔の箱は見直しが確かめるまで描かれない。顔が見えたら `face` で指す）に 10×10 の升（列 A〜J・行 1〜10、目印係と同じ）。
  **見るのはこの絵だけ。** 元の写真（`file`）は開かない。

## 指す物（kind と箱の文字）
| kind | 文字 | 例 |
|---|---|---|
| `poster` | 掲示物 | 貼り紙・ポスター・掲示板の紙・立て看板の告知・ホワイトボードの文字 |
| `name` | 人名 | 表札・名札・部屋の札の人の名前 |
| `phone` | 電話番号 | 電話番号・内線番号の書かれた札 |
| `face` | 顔 | 見えている顔（小さい・横顔・後ろ姿で顔が分かる物も）。自動の箱は描かれていないので、顔が見えたら指す |
| `plate` | ナンバー | 車・バイクのナンバー（**自動では見ていない**。必ず目で探す） |

建物の名前の看板・案内の矢印・消火栓や非常口の標識・床の表示は**塗らない**（掲示物ではなく、模型の目印にもなる）。迷えば塗る側に倒し、`note` に迷った理由を書く。

**研究・研究室に関する物**（研究室の名前の札・研究内容のポスター・実験装置が見える窓・研究室の中）が写っていたら、塗らずに写真ごと外す（`exclude` に理由）。大学の条件で、塗りつぶしでは済ませない。

## 手順
1. `tasks_<フォルダ>.json` を読み、写真ごとに `grid` の絵を読む。
2. 指す物があれば、それを**すっかり覆う**升の範囲を「左上の升:右下の升」で書く（例 `C3:E5`。1 升だけなら `D4`）。はみ出しても覆い切る方を選ぶ（1 升広くてよい）。
3. 画像の**端**にある掲示物は、箱の代わりに残す範囲（`crop`、例 `A1:H10`＝右の 2 列を切り落とす）でもよい。真ん中の物は切り落とさない。
4. `write_to` の道（`out/photos/hogo_<フォルダ>.json`）に書く：
```json
{"pass": "hogo", "made_by": "保護係（haiku）", "made_at": "2026-11-08T10:00:00",
 "folder": "<フォルダ>",
 "photos": {
   "<写真id 1>": {"masks": [{"kind": "poster", "cells": "G2:H4", "note": "柱の貼り紙"}], "ok": true},
   "<写真id 2>": {"masks": [], "crop": "A1:H10", "ok": true},
   "<写真id 3>": {"exclude": "研究室の名前の札が読める（右の窓）", "ok": true},
   "<写真id 4>": {"masks": [], "ok": true}
 },
 "questions": []}
```
   見た写真は**指す物が無くても全部** `photos` に入れる（`"masks": []`）。入っていない写真は「まだ見ていない」と数えられる。
5. 索引への書き戻しは道具だけ：`.venv/Scripts/python -I -X utf8 -m recorder photos masks --from out/photos/hogo_<フォルダ>.json`。
   升の書き方が違えば `errors` が出てその写真は書かれない。直して同じコマンドをもう一度（同じ pass の前の箱は置き換わる）。
6. 報告は日本語 5 行以内：見た枚数・塗った枚数（種類別）・外した枚数と理由・迷った写真。

## 見直しの時（同じ定義を Sonnet で呼ぶ。task に「見直し」とある時）
- 入力は同じ `tasks_<フォルダ>.json` と、索引の `masks`（`recorder photos list` では見えないので `data/photos/index.json` を**読むだけ**）。
  公開版ができていれば `data/photos/public/<フォルダ>/<id>.jpg`（塗った後の絵）を見て、塗り残し・塗り過ぎを探す。
- 書き出しは `out/photos/hogo_<フォルダ>_review.json`、`"pass": "review"`、`"made_by": "見直し（sonnet）"`。
  - 塗り残し → `masks` に足す（保護係の箱はそのまま残る）。
  - 塗り過ぎ（建物の名前の看板・標識を塗った等）→ `drop` に保護係の升をそのまま書く（例 `["G2:H4"]`）。
  - 外し過ぎ → `"include": true`（外す理由が無い時だけ）。外し漏れ → `exclude`。
- **自動の顔の箱は切り出しを見て `confirm` か `drop` を必ず書く**（`recorder photos hogo-grid --refine --auto` の絵。依頼の JSON に `by: auto`・`score`）。顔なら `{"n": 0, "confirm": true}`（`cells` で締めてよい）、石垣・壁の模様なら `{"n": 0, "drop": true}`。書き方は寄せの JSON（`--pass refine`）か、見直しの JSON の写真ごとの `"auto": [...]`。確かめていない自動の箱は公開版にも縮小版にも描かれない。
- 見たが**変えなかった**写真の id は、トップに `"seen": ["<写真id>", …]` で入れる（見直し済みの記録が付く。`photos` に入れた写真は入れなくてよい）。保護係の pass も同じ。
  まとめて付けるなら `recorder photos masks --pass review --seen-from out/photos/hogo/tasks_<フォルダ>.json`（または `--mark-seen id,id`）。
- 書き戻しは `recorder photos masks --from out/photos/hogo_<フォルダ>_review.json`。その後 `recorder photos publish` で公開版を作り直す。

## 寄せの時（task に「寄せ」とある時。1 段）
10×10 の升の箱は粗く、細い垂れ幕の周りの壁まで塗ってしまう。箱ごとに寄りの絵で**本当に隠す範囲**を指し直す（目印係の寄りと同じ言い方）。
1. 道具が出す：`recorder photos hogo-grid --refine --photos <id,…>`（または `--building <棟>`）。
   箱を各側に箱の 0.25 だけ広げた 1.5 倍の範囲で切り出し、10×10 の升目を引いた寄りの絵 `out/photos/hogo_refine/<写真id>_<n>_grid.jpg`
   （n は索引の masks の番号）と依頼 `tasks_refine[_<棟>].json`（`photo`・`n`・`kind`・`box`・`grid`・`write_to`）。
   **赤の線が元の箱。** 寄りの升で、赤の線の中にある隠す物を覆う範囲を書く（赤の線より外は書いても切り詰められる＝元の箱より広げない）。
2. 隠す物が 2 つ以上に分かれていれば分けて書く（例 垂れ幕 2 本 → `["C2:D9", "G2:H9"]`）。間の壁は塗らない。
   覆い切る方を選ぶ（端が升の境に近ければ 1 升広く）。文字・名前が少しでも残る書き方はしない。
3. 隠す物が無かった（塗り過ぎ）と思う箱は寄せでは消せない。`note` に書いて、見直しの `drop` に回す。
4. `write_to`（`out/photos/hogo_refine[_<棟>].json`）に書く：
```json
{"pass": "refine", "made_by": "保護係（haiku）", "made_at": "2026-11-08T12:00:00",
 "photos": {
   "<写真id>": [
     {"n": 1, "box": [0.6, 0.2, 0.7, 0.4], "cells": ["F2:I9"], "note": "垂れ幕 1 本"},
     {"n": 3, "box": [0.8, 0.1, 1.0, 0.4], "cells": ["E4:G9", "I3:J9"], "note": "垂れ幕 2 本"}
   ]}}
```
   `n` と `box` は依頼の JSON から写す（箱が依頼の時と違えば道具が止める）。
5. 書き戻しは道具だけ：`recorder photos masks --pass refine --from out/photos/hogo_refine[_<棟>].json`。その後 `recorder photos publish`。
   1 つの箱に細い物が 3 本以上並び、寄せても間の壁が出ない時は、同じ 1〜5 をもう一度回してよい（寄せた箱をさらに寄せる）。

## やらない
元の写真を開く・写す・書き換える。ぼかし・モザイク・周りの模様で埋める指示を出す。索引や公開版のファイルを自分で書く。
寸法・棟・面を書く。研究室が分かる写真を塗りつぶしで済ませる。
