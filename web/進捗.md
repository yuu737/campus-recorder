# Web 3D 進捗（土台＋本部棟＋タワー75）
## できたこと
- `recorder site export-web`（site.py の export_web）で web/data/site.json（地面 4m 格子・PLATEAU の箱 77 件・設計済み棟の根拠件数）と web/data/models/{honbu,tower75}.glb を出す
- web/index.html：three.js 0.170.0（jsdelivr、import map）。地面に沿って目線 1.6 m で歩く（格子の双一次補間、Raycaster は棟タップ用）。WASD＋ドラッグ／スマホは左スティック＋右ドラッグ。凡例、棟の札（id・名前・measured/estimated/unknown 件数）、本部棟・タワー75 へ飛ぶボタン
- 375px 幅で横スクロールなし、札はスマホでは下寄せ
## 未了・注意
- 図書館は glb が 2KB の仮物のため箱（橙）で出している。11号館は glb なし（箱・橙）
- 壁・地面の当たり判定なし（建物を通り抜ける）。タッチ実機は未確認（エミュレートのみ）
- 地面は 5m 標高を 4m 間隔に間引き、欠け 3.2% は隣の値で延長
- unknown 件数は棟 JSON の status=unknown を数えた値。本部棟は 0
## glb の軸
glTF は Y 上。x=東、y=高さ、z=-北。y は ground_z 基準の相対値（honbu 0〜32、footprint と z=-北 で一致を確認）。置く時に ground_z を足す
