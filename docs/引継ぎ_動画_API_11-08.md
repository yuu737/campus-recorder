## 4. 完成度の決まり（見本から学んだ作り）
- 0.5〜1 秒に 1 つ何かが変わる。1 秒以上止まるのは締めの最後だけ。
- 左 1/4 の柱＝係の一覧（今の係が点く、モデル名は `.claude/agents/*.md` の model: の実値）。右 3/4＝本文。
- 本物の画面は寄り（2〜3 秒で 100→110 %）と注目点の枠＋周りの暗転。カーソルは人の速さ、クリックに波紋。
- 係ごとに仕組みの図を 1 つ（SVG 自作。色は立面図の凡例：黒＝実測、琥珀＝推定、赤破線＝未確定）。
- 見出しは画面の高さの 1/8 以上、数字は 1/5。字幕の大きさの字は出典だけ。
- 配色・質感は導入 v7 と同じ（方眼紙の地、差し色 1 つ）。
