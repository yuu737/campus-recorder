### K-101 measured の定義（B 案。模擬採点 `docs/過程/審査_模擬採点_measured_11-07.md`）
- 値に至る根拠の鎖の**全部の輪**が次の 3 種のどれかなら measured：①メジャーの目盛りの読み（写真 id）②写真から数えた個数（写真 id）③同じ面を正面化した 1 枚の画像の中で測った px の比（写真 id と px）。
- 鎖のどこかに目視の比率・「同じタイル」などの申告・別の面と同じという仮定・公開資料の値・典型値が 1 つでも入れば estimated（方法と根拠は書く）。写真が無い面は今まで通り仮説か unknown。
- 状態は規約 1 番のまま 3 つ（measured／estimated／unknown）。4 つ目の状態（derived）は作らない。代わりに measured の値に `measured_kind`（`direct`＝メジャーと同じ写真・同じ面で直接読んだ区間、`chain`＝鎖）を持たせ、集計・図面・README で「直接 n 件／鎖 m 件／個数 k 件」を分けて見せる。
- 審査員 4 人が付けた条件：
  1. 「同じ面では周期が一様」を鎖の輪（`uniform_period`）として明記する。根拠は、正面化した面の全体で自己相関の周期（px）が一様なこと（数で書く）か、面の別の場所のメジャー写真での検算。どちらも無ければその面は estimated。
  2. ± は輪ごとに積む：メジャーの読み（両端 ±0.5 cm ÷ またがった枚数）＋ 数え違い（±1 枚 × 周期）＋ 正面化の px の誤差。± の無い measured（個数を除く）は検証で落とす。
  3. 鎖そのものを棟 JSON に書き、検証は各輪に写真 id があるかを見る。
- 利用者の申告（タワー75 と共通講義棟南は同じタイル、本部棟と図書館は同じタイル、目地は全部 1 cm）は**確かめる物**で、根拠にはしない。棟をまたいで周期を使うのは、その棟にメジャー写真が無い時だけで、その時は estimated（申告の輪）。仕分け係の目視では、本部棟の縦の伸縮目地とタワー75 f11 の黒いシーリング目地は 1 cm より太い → 割り付けから外す。

### 鎖の書き方（T1 と T2 と設計係が同じ形を使う）
値の形は今のまま（`value / unit / tol / status / evidence / method / note`）。measured の長さには次を足す。
```json
{"value": 5.46, "unit": "m", "tol": 0.035, "status": "measured", "measured_kind": "chain",
 "evidence": ["本部棟正面柱92cm", "PXL_20261103_042900775"],
 "method": "タイルの周期（メジャー）× 枚数（正面化した写真で数えた）",
 "chain": [
   {"link": "tape", "photo": "本部棟正面柱92cm", "read": "0→91.0 cm", "n": 4, "what": "tile_pitch_h", "value": 0.2275, "tol": 0.00125},
   {"link": "uniform_period", "photo": "PXL_20261103_042900775", "px": [38.1, 38.4, 38.2, 38.3], "what": "正面化した f6 の全体で横の周期が一様（±0.5 %）"},
   {"link": "count", "photo": "PXL_20261103_042900775", "n": 24, "what": "柱型の縁から縁のタイル枚数", "tol": 1},
   {"link": "px_ratio", "photo": "…", "px": [180, 910], "what": "パラペット÷階高"}
 ]}
```
- `link` は `tape | count | px_ratio | uniform_period` の 4 つだけ。これ以外（`eye`, `claim`, `plateau`, `typical`, `assume`）が鎖にあれば status は estimated でなければならない（検証で落とす）。
- `measured_kind: direct` は鎖が `tape` 1 輪だけの時。`chain` はそれ以外。
- 個数の値（unit が 階・本・枚・台・スパン・段）は従来どおり evidence だけでよい（鎖は `count` 1 輪と見なす）。
- `tol` は鎖から積んだ値以上でなければならない（検証：`chain_tol(chain, value) <= tol`）。
