## 広さの出し方（本部棟だけにしない）
1. 土台はキャンパス全体（PLATEAU の全棟の箱・国土地理院の地形・OSM の道）を最初から歩ける状態に
2. 撮った棟から順に、灰色の箱が根拠付きの建物に変わる。両端が写っていない棟は unknown と撮影依頼のまま灰色
3. 数字で締める：n 棟、写真 m 枚、寸法 k 件すべて根拠付き、unknown j 件は撮影依頼に

## 使用量の運転規則（Max 5x、追加課金なし）
- 係が 1 本終わるたび・新しい係を出す前・1 時間に 1 回、`get_usage` で読む
- 5 時間枠 85% 超：新規は出さない。100%：回復を待つ（強制停止はしない）
- 週・全モデルが 1 晩で 15% 以上増えたら、コード系の係を Opus → Sonnet。写真を見る係は Opus のまま
- 週・Fable 45% 超：Fable は係の報告の要約だけ読んで判断する。11/7〜8 用に Fable を 40% 前後残す
- 同時に走らせる係は 2〜3 本まで

## モデルの割り当て
| 役 | モデル |
|---|---|
| 撮影係（速い返事） | Haiku |
| 仕分け・観察・数え・測量 | Opus（写真を見て決める） |
| 設計・検収 | Opus が書き・回し、Fable が節目で判断 |
| 製図・模型 | コード |
| 実装（コード）の係 | 写真と JSON を見る物は Opus、仕様が明確な物は Sonnet |
