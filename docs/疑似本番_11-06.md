## 回し方（棟ごと。登録の工程は 3 棟を直列に）
1. `python -I -X utf8 scripts/trial_reset.py <id>`：設計スクリプト・棟 JSON・係の報告（`data/reports/<id>/`。11/7 に対象へ追加）・登録台帳・索引の face を退避
2. `python -I -X utf8 -m recorder agent tasks <id>`：`out/<id>/agent_tasks.md` に係ごとの依頼文
3. 係を順に呼ぶ（依頼文をそのまま `subagent_type=<係>` に渡す）：satsuei → shiwake → kansatsu → kazoe → sokuryo → sekkei → コマンド `run --fast` → seizu → mejirushi → kenshu → コマンド `run` → `site export-web --with-coverage`
4. 1 工程ごとに `recorder agent log <id> --step <係>`、`recorder agent events <id>` を見る。stuck・vocab・asset が出たら shinko
5. 各工程の後に `recorder validate --strict data/buildings/<id>.json`。警告が出たら、その係に差し戻す（値は係が直す。指揮役は直さない）
6. 終わったら `trial_reset --restore` を退避の逆順で（全棟の索引の face を戻すため）
