## 3. プロジェクト概要（20:00 提出した文。利用者が決定。「数週間」は出典なし、正直な限界の 1 文は時間切れで外した）
```
このプロジェクトは、交通費や日数でキャンパスを見に行けない遠くの受験生と、歩ける3Dを作りたくても予算も専門家もいない大学の職員の課題を、職員がスマホで撮るだけで根拠付きの建物を起こし、受験生が家からスマホで歩いて確かめられる形に変える、Web 3Dのキャンパスを作成するためのツールです。

地方から1泊2日で遠方のキャンパスを見に来ると数万円です。360度写真の案内は歩けず、建物どうしの距離や坂、駅からの道のりが分かりません。職員が建物1棟の3Dを外注すると約4万〜100万円・数週間。図面が要り、測る作業は別です。この道具では、職員の写真をClaudeの係（撮影はHaiku、測量や設計はOpus、進行役はFable）が読んで判断し、計算はコードが行い、本部棟を0から歩ける3Dまで1時間56分・19.80 USDで通しました。値は写真番号つきの実測・方法を書いた推定・空欄のどれかで、測れない面は職員に撮影依頼が返ります。途中で止まっても同じ記録の続きから再開でき、行き詰まりは進行役が決めて進み、職員は後で承認か取り消します。
```
