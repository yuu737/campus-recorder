## 3. プロジェクト概要（498 字）
```
このプロジェクトは、予算も3Dの専門家もいない大学の「建物の3D化を外注すると1棟約4万〜100万円かかり、遠くの受験生にキャンパスを届けられない」課題を、職員がスマホで撮るだけで1棟約2時間・約3千円に縮め、受験生が家からスマホで歩いて確かめられる形に変える、根拠付きのWeb 3Dキャンパスです。

本部棟で0から通しました。写真と職員の申告だけの状態から、Claudeの係（撮影はHaiku、仕分け・測量・設計・検収はOpus、進行役はFable）が写真を見て判断し、計算はコードが行い、歩ける3Dまで1時間56分・API費用19.80 USD。外注の相場は図面がある前提で、測る作業は別です。値はすべて写真番号つきの実測・方法を書いた推定・空欄のどれかで、測れない面は「坂の下から面全体が入る1枚をください」と職員に撮影依頼が返ります。職員が正面の柱にメジャーを当てて撮って送ると、柱間5.310 mが推定から実測に変わりました。ハッカソン後は職員が撮って足し、棟JSONと撮影依頼ごと次の担当へ引き継ぎます。正直な限界：0からの実走は推定の模型までで、製図で1回、人が決定を手で入れました。
```
