  - f8：面の線 70 本中 29 本が合格。f6 のような縮尺のずれの形は無く、強い見上げの広角で撮った錨の写真の視点の残りと読んでいます。**f8 の柱間 5.408 m は、f6 の 11/7 の古い縮尺から移した値**で、新しい鎖では測り直していません（争点として open。撮影依頼「f8 の柱型にメジャーを当てて撮る」）。
  - f4・f5・f7 は撮影依頼が open のまま、不合格の面として記録して進めました（K-404）。
  - README の「到達点」の表の本部棟の「検収で合格した面」は、検収係のまとめ（`kenshu_summary.json`）の最新の回から数えた物です。不合格の面の数は記録（回・決定）によって数え方が違うので、ここには書きません。
