## 2. 収録の手順

1. **画面**：1920×1080、Windows の表示の拡大 100%。通知を切る（集中モード）。Edge は F11 で全画面。エディタ（カット 4・§3 B の 7）は文字を 20 px 以上に拡大し、見せる行だけ折りたたまずに出す。
2. **録画**：OBS（キャンバスと出力 1920×1080、30 fps、記録は mkv→mp4 に再多重化）。OBS が無ければ Windows の Game Bar（Win+Alt+R）。ナレーションは別に録って編集でのせる。
3. **配信**：全部 `recorder serve --port 8767`（`.claude/launch.json` の `serve`）1 つで出す。入口は `http://localhost:8767/web/hub.html`、歩く画面は `http://localhost:8767/web/index.html?cam=…`、報告は `http://localhost:8767/out/honbu/report.html`、職員の画面は `http://localhost:8767/web/staff.html`（serve は web/・out/・data/photos/ を配る）。8766 の `root`（静的配信）は使わない。
4. **§3 の「前」を先に残す**：撮る前に、`out/honbu/elev_SE.svg` のブラウザ表示と、歩く画面で本部棟の南東端面が見える構図（「根拠で見る」で灰色）を録っておく。後から「前」は作れない。
5. **歩く画面（カット 3・10）**：`?cam=-47.42,-58.51,45.50,27.80,13.40,77.57`（`out/honbu/model_report.json` の `web_cameras.street`）で開く。速さを一定に、急に振り向かない。3 回録って一番なめらかな物を使う。
6. **静止画のカット**は編集ソフトでゆっくり寄る（2〜3 秒で 110%）だけ。絵そのものは直さない（生成物を手で直さない決まり）。切り出しは枠を決めるだけ。
7. 終わったら headless の Edge と Rerun を閉じる（GPU を掴み続けるため）。
