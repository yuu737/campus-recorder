## 4. 撮り方

```powershell
cd D:\BuiltwithClaude
.\.venv\Scripts\python.exe -I -X utf8 scripts\video\app\make_app.py
.\.venv\Scripts\python.exe -I -X utf8 scripts\video\render_html.py --page scripts/video/app/04_sokuryo/index.html --out out/video/app/04_sokuryo --at 0 --at 2.6 --at 3.5 --at 13.8
```

- `make_app.py`：係の一覧・時刻表・再生の 1 コマを用意する。
- `render_html.py`：静止画を `out/video/app/<場面>/frames/at_<秒>.png` に撮る。
- 確認用に 1 秒おきの絵と montage が欲しい時は `--stills 1`。動画にする時は `--at` を外して `--mp4 out/video/app/<場面>.mp4`。
- **9 場面の 4 枚をまとめて撮り、`out/video/app/stills/` と `00_一覧.png` まで作る**：`.\.venv\Scripts\python.exe -I -X utf8 scripts\video\app\keys.py`。1 場面だけ撮り直すなら、後ろに `04_sokuryo` のように場面の名前を付ける。一覧は全場面から作り直す。
